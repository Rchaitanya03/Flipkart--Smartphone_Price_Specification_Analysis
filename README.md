*Flipkart Smartphone Price and Specification Analysis*

Project Overview

This project uses web scraping to collect smartphone prices and specifications from Flipkart. The collected data is cleaned and analyzed to understand product pricing, brand distribution, and smartphone features.

Tools & Technologies

Python

Jupyter Notebook

BeautifulSoup

Requests

Pandas, NumPy

Matplotlib, Seaborn

Project Workflow

Scrape smartphone data from Flipkart across multiple pages.

Clean and preprocess the collected data.

Analyze prices, brands, colors, RAM, storage, battery, and display specifications.

Create visualizations to identify pricing patterns.

Generate business insights to support product and pricing comparisons.

Key Insights

Compare smartphone prices across brands.

Analyze price distribution and price segments.

Explore relationships between prices and specifications.

Identify missing product information and potential value-for-money options.
